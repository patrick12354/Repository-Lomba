# SPARC 2026 Data Science Competition

🥇 **Juara 1 dari 130 tim** · Universitas Ciputra · Feb – Mar 2026

Lomba data science nasional. Tugasnya memprediksi prioritas follow-up repeat order di industri otomotif, supaya tim sales fokus ke pelanggan dengan peluang konversi tertinggi.

## Isi

| Berkas | Isi |
|---|---|
| `1) Labeling.ipynb` | Pelabelan target |
| `2) EDA.ipynb` | Eksplorasi data |
| `3) Modeling Baseline.ipynb` | Model baseline |
| `4) Modeling Catboost.ipynb` | Model CatBoost |
| `5) Modeling LBGM.ipynb` | Model LightGBM |
| `SPARC gabungan.ipynb`, `combine notebook.ipynb` | Notebook gabungan end-to-end |
| `dataset.rar` | Dataset lomba |
| `catboost_info/` | Log training CatBoost |
| `trash/` | Versi lama notebook modeling |

Urutan menjalankan: 1 → 5, atau langsung `SPARC gabungan.ipynb`.
