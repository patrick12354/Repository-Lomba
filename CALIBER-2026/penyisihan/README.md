# PlantPulse — CALIBER 2026 Penyisihan

> Babak penyisihan Chandra Asri Innovation and Business Strategy Challenge (CALIBER) 2026, Case 2: Intelligence Manufacturing (hasil akhir: 🥇 Juara 1 dari 120 tim). Repo asli: [raphaeladikara/Caliber-2026-Heisenberg](https://github.com/raphaeladikara/Caliber-2026-Heisenberg)

**PlantPulse** adalah workspace keputusan dan tindak lanjut reliabilitas untuk engineer di pabrik petrokimia. Tiap masalah peralatan ditautkan ke bukti sumbernya, ketidakpastiannya, pemiliknya, dan kriteria selesainya. Tujuannya supaya keputusan bisa ditelusuri dan tindakan korektif/preventif benar-benar terverifikasi selesai, bukan cuma mesinnya kembali jalan.

Stack: React + TypeScript + Vite di Vercel, Vercel Functions, Supabase, OpenAI API; ekstraksi data offline dengan Python.
